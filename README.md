# Security4Her live location

The page family members open from an SOS text. It shows her live location on a map while an SOS or a
live share is running. The phone posts each location to a private [ntfy.sh](https://ntfy.sh) topic; this page
reads it (`?t=<topic>`). Nothing is stored here.
